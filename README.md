# Практикум и ДЗ: потоки и гонка

## Состав

- `server.c` - TCP эхо-сервер на C. Создаёт отдельный поток для каждого клиента. Общий счётчик подключений защищён мьютексом.
- `race_demo.c` - пример гонки двух потоков до применения мьютекса и после.
- `test_clients.py` - проверка трёх одновременных подключений, эхо и правильного завершения сервера.
- `результаты_проверки.txt` - фактический вывод программ при запуске.
- `Отчёт.docx` - краткий отчёт о практикуме.
- `Эссе.docx` - одна страница о проблемах многопоточности.

## Требования

Linux, GCC, Python 3 и библиотека POSIX Threads.

## Сборка

```bash
gcc -std=c11 -Wall -Wextra -O2 -pthread server.c -o server
gcc -std=c11 -Wall -Wextra -O0 -pthread race_demo.c -o race_demo
```

## Проверка гонки

```bash
./race_demo
```

Оба потока увеличивают одно число по 300000 раз. Без мьютекса значение может быть меньше 600000. С мьютексом результат всегда 600000. Числа без мьютекса могут отличаться при каждом запуске, так как порядок выполнения потоков не фиксирован.

## Проверка сервера

```bash
python3 test_clients.py
```

Тест сам запускает сервер на `127.0.0.1:9092`, подключает три клиента, проверяет возвращённые сообщения и останавливает сервер сигналом SIGINT.

Для запуска сервера вручную:

```bash
./server
```

Для подключения из другого терминала:

```bash
nc 127.0.0.1 9092
```

После ввода текста сервер возвращает этот текст. Для остановки нажмите Ctrl+C. Сервер завершает клиентов, закрывает сокеты и дожидается завершения потоков.
